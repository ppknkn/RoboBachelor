# 已知问题与限制

| 项目 | 实际状态与影响 |
| --- | --- |
| 新IMU后端 | 完整源码、Keil链接和主机模拟通过，尚未真机验证；时延、磁刷新、轴符号、温漂与动态响应需复核，不保证旧固件行为等价 |
| 原接收机解析 | 保留0x0F起始/18字节候选及byte6拨杆位；与标准SBUS/DBUS布局有冲突，CH9模式/真实STOP映射未核实，UART8B+Even配置也有数据位疑问。未猜测并替换协议 |
| HOLD与启动 | 原启动请求使能；没有新增失联保护。HOLD可能持续旧指令，STOP解析未在本轮硬件验证 |
| STOP输出 | 已抑制新关节运动目标并请求零轮力矩；可能仍保持电机内旧位置目标，不等同禁能/卸力/物理断电 |
| 反馈与总线 | 没有完整电机反馈超时/ACK确认、独立watchdog或最坏停止延迟验证 |
| 轮反馈单位/符号 | 右轮速度取负而位置累计左右相加；JC两类反馈速度缩放不同、主循环不主动轮询轮反馈，待按实物协议核实，未凭猜测更改 |
| 时序 | 名义控制门限2ms，IMU在未限频主循环中调用，SPI/串口和CAN相关阻塞会影响实际节拍，未测最坏时延 |
| 几何错误 | 无效几何已有确定返回值，但完整上层错误传播未设计，不称运动学已全域验证 |
| 模型 | 11份原生文件原字节保留；未打开/重建/导出或验证装配依赖、专有元数据与制造完整资料；无现成STEP/STL |
| DM模型通知 | 作者已向达妙官方确认MIT；本次没有独立取得该文件的原始版权通知，保留此来源限制，不伪造署名 |

新环境安装、刷写、实物闭环、电流、热、机械极限与长期运行均未测试。旧未许可A板代码不再属于公共源码依赖。
