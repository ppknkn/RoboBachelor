# 首次检查

本轮只做编译和离线测试；新IMU后端、电机响应和装配均未实物验证。

1. 物理断开电机动力，再检查板卡供电、接地、绝缘、调试接口和接线；没有完整针脚图的连接器查原图，不猜接线。
2. 先运行离线测试及Keil完整重建。新版会在IMU初始化成功及收敛后沿原流程请求使能；没有ARM口令或默认禁能宏，连接调试器后不要自动运行。
3. 动力断开时读取IMU初始化结果、原始计数、温度、rol/wx及yaw/wz，核对轴向、静止零偏、磁样本和刷新时序。主机模拟不能代替这些检查。保留旧调通版本归档，发现差异先记录而不是直接修改PID掩盖。
4. 核对RF209S CH9实际模式和原STOP拨杆，观察完整字节与ROBOT_ESTOP状态；HOLD不是失联停机。保持现有解析不代表协议正确，见[receiver-rf209s.md](receiver-rf209s.md)。
5. 具备实际电气/机械资料的操作者再安排限流、固定机体、悬空轮、独立断电和逐轴验证。先核对STOP时轮零力矩及关节目标抑制的实际结果，不能以软件状态或CAN入队成功代替电机确认。
6. 核对电机ID、反馈、方向、限位、校准和时延后再评估起身/闭环。倾倒或IMU健康错误沿原motor-disable路径锁存，退出STOP不解除此故障锁存。记录每次改动和硬件结果。
